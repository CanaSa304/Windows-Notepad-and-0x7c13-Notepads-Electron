# Windows Notepad and 0x7c13/Notepads（Electron）

A simple text software that opens and edits easily and effortlessly.

If you encounter any problems, please contact the email: pashpon@qq.com.

You can also download my community software to get more comprehensive support.

We will later add built-in community software, which may take a little time.

If you don't need the full community software, you can delete it in the folder.

The deletability of community software may change depending on changes in community policies.

The project inherits from https://github.com/0x7c13/Notepads and has been refactored and redesigned. Thank you for using it.
